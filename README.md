# 像素小猫 PixelCat · 0.5 原型

根据你的猫照片制作的独立原生桌面宠物。无需联网、浏览器运行时或 AI 模型。

## 启动

- macOS 12 或更新版本：打开 `dist/PixelCat.app`。同一应用包含 Apple Silicon 和 Intel 两种架构；已在本机 Apple Silicon 上启动验证。菜单栏会出现 🐾，无 Dock 图标。
- Windows 10/11 x64：将 `dist/PixelCat-Windows` 整个目录复制到电脑，再打开 `PixelCat.exe`。八张 PNG 素材必须全部保留在 exe 同目录。Windows 已交叉编译，尚未在 Windows 机器运行验证。
- 构建为本地原型，Mac 使用临时签名，没有 Apple 公证；Windows 没有发行者签名。分发到其他电脑时可能出现系统验证提示。

## 0.5 新增姿势

「动作」现在共六项，新增：耍帅、趴着卖萌、蜷身小憩。保持 8 秒展示、轻微摆动、点击/拖拽结束、暂停/隐藏时停止倒计时。它们属于照片姿势展示，不替换自动睡眠动作。

三张新增素材通过内置 imagegen 根据用户照片与原像素猫生成，提示保留银白毛色、蓝灰眼睛、粉鼻子、圆脸，并分别表现低头垂眼、下巴贴地伸出一只前爪、侧卧蜷身枕爪；要求完整角色、像素风和透明背景。带光晕的中间版本未打包。最终文件为 `downcast.png`、`stretch.png`、`doze.png`。

0.5 两端编译、六项动作生命周期测试和新增素材透明度测试通过；新版界面尚未实机复验。仍然只加载当前一个姿势，新增素材不增加同时缓存的图像数量。

## 动作（0.4 新增）

右键小猫或打开菜单栏 / 托盘 →「动作」：
- 鸡腿：参考举起后腿的照片。
- 花花：参考黄色花瓣头套照片。
- 翻肚皮：参考仰躺露肚皮照片。

每项展示 8 秒，使用独立透明像素风姿势图加轻微摆动；并非逐帧理毛或翻滚动画。展示期间停止自动走动，结束后回到待机。点击或拖拽可立即结束；暂停和隐藏期间不倒计时。花花当前是临时姿势，不是应用到所有动作的永久装扮。

只按需解码当前姿势（最长边 512 像素），切换时替换、结束后释放，额外常驻像素数据不超过约 1 MiB，不含原图加载的瞬时峰值。三张素材分别为 `assets/groom.png`、`assets/flower.png`、`assets/belly.png`。使用内置 imagegen，以原像素猫保持外观，分别按用户三张照片生成完整透明角色，保留银白毛色、蓝灰眼睛、粉鼻子、灰额纹和对应姿势。未采用背景不合格的六格图集。

0.4 验证：Mac 通用包 / Windows x64 编译、行为测试（动作结束、切换、暂停、唤醒及打断）、三张姿势图解码与透明度检查。新版 GUI 尚未重新实机验证，Windows 尚未实机运行。

## 操作

- 右键小猫 → 调整大小：50%、75%、100%（默认）、125%、150%、200%；两端自动记住所选尺寸。缩放保持宽高比，并尽量保持脚底中心位置，靠近屏幕边缘时自动收回工作区域。
- 按住小猫拖拽；松开时限制在显示器工作区域。
- 点击小猫：唤醒并轻轻跳一下；拖拽期间停止自动移动。
- 待机：轻微呼吸起伏，8 次/秒刷新。
- 自动走动：默认开启，启动或互动约 8 秒后开始走动，每轮走约 5 秒，屏幕左右边界自动转向；菜单可关闭并记住选择。
- 自动睡觉：默认开启，两分钟没有与小猫互动后进入睡眠；菜单可关闭并记住选择。暂停或隐藏期间不累计时间。
- 手动睡觉 / 唤醒：菜单可立即切换，睡觉时每两秒刷新一次；点击或拖拽会唤醒。
- 右键小猫，或使用菜单栏 / 系统托盘菜单：暂停、显示/隐藏、恢复位置、退出。
- Mac 会保存拖拽后的位置；Windows 当前启动时默认显示在右下角。
- 暂停和隐藏时停止动画计时器。

## 当前范围

这是可运行的交互原型：坐姿使用原来的角色图，走路和睡觉分别使用两帧像素风素材；走路属于简化动画，尚非流畅的多帧步态。还没有眨眼、喂食或聊天。Mac 窗口的透明空白区域仍可能接收鼠标点击；尚未实现逐像素点击穿透。Windows 高清屏尺寸适配仍需实机检查。

## 资源占用与验证

以下为旧版 0.1 的 Mac ARM64 启动 10 秒采样，不代表新版 0.3 的实测结果：

- physical footprint：20.24 MiB。
- resident size / RSS：35.56 MiB。
- 0.3 常驻像素数据预算：坐姿 384 × 512 + 动作图集 512 × 512 RGBA，合计约 1.75 MiB，不含窗口缓冲、框架和原图加载峰值。新版进程内存尚未重新实测。

应用启动 10 秒后尝试在应用旁写入 `PixelCat-metrics.json`，只含本进程内存与图像尺寸，供本地调试，无网络上传。若目录不可写则跳过保存。

0.3 已验证：Mac 通用包和 Windows x64 编译；Mac 本地签名；行为逻辑测试（暂停、睡眠阈值、点击唤醒、开关和双向边界转向）；动作图集四帧解码及透明度检查。桌面控制连接超时，0.3 界面、步态衔接和菜单仍需人工运行检查。0.1 的 Mac 窗口和暂停菜单曾通过运行验证；Windows 始终尚未实机验证。

## 源码与构建

`src/motion.h` 共用动作与边界逻辑；`src/mac.mm` 使用 AppKit/ImageIO；`src/windows.cpp` 使用 Win32/GDI+。没有第三方库。

Mac（安装 Xcode Command Line Tools）：

```sh
sh build-mac.sh
```

Windows x64 交叉编译（安装 MinGW-w64）：

```sh
sh build-windows.sh
```

在 Windows 的 MinGW-w64 环境下，也可从项目根目录运行：

```sh
g++ -std=c++17 -O2 -static -static-libgcc -static-libstdc++ -municode -mwindows src/windows.cpp -lgdiplus -lshell32 -lgdi32 -luser32 -ladvapi32 -o PixelCat.exe
cp assets/*.png .
```

逻辑验证：

```sh
clang++ -std=c++17 tests/motion_test.cpp -o motion-test
./motion-test
```

角色图由内置 imagegen 根据用户提供的猫照片生成并经用户选择。原始像素风 PNG 保存在 `assets/cat.png`，两帧走路、两帧睡眠图集保存在 `assets/actions.png`；程序加载时创建小尺寸缓存，源图没有被覆盖。

## 动作素材生成说明

使用内置 imagegen，以已确认的像素猫为参考：生成透明背景的 2×2 等分图集，左上、右上为朝右走路的两个交替步态，左下、右下为闭眼蜷卧的两帧。保留银白毛色、灰色额纹、蓝灰眼睛、粉鼻子、圆脸和自然腿长；不加文字或背景。程序按四象限读取，左右行走使用同一图集镜像绘制。
